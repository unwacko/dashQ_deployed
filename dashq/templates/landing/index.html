Three ways to join

All three end up on the same board, marked QR, NFC or IP, so you can see how each person joined.

{{ ui.icon("qr") }}
Scan a QR code

Put it on a table, door or bill. It opens in the phone's browser.

{{ ui.icon("nfc") }}
Tap an NFC sticker

Put it on the counter. The customer taps their phone on it to join.

{{ ui.icon("person") }}
Join in person

Staff add walk-ins and phone calls from the dashboard.

Setup

Three steps to start

1
Make your account

Sign up with your email. You get a join link and a QR code.

2
Set up your pages

Choose which details to ask for, add a list of items or services, and add links or text. Or turn them off and only give tokens.

3
Put up the QR code

Print the QR code or write the link to an NFC sticker. Run the line from the dashboard.
